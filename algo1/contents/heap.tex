\section*{(Min-) Heap}
Vollst. Binärbaum mit Eigenschaft:

$u$ Parent von $v \implies \key(u) \le \key(v)$

Alle Operationen mit Laufzeit $\bigO(\log n)$.

\subsection*{Heapify($u$)}
Annahme: Parent $u$ größer als Child.
Aber beide Teilbäume erfüllen H-Eigenschaft.
\begin{enumerate}
	\item Tausche $u$ mit kleinstem Kind $v$
	\item Rekursiver Aufruf: Heapify($v$)
	\item Stoppe, wenn H-Eigenschaft erfüllt
\end{enumerate}

\subsection*{IncreaseKey($u$)}
\begin{enumerate}
	\item Erhöhe Schlüssel von $u$
	\item Heapify($u$)
\end{enumerate}

\subsection*{DecreaseKey($H,u,b$)}
\begin{enumerate}
	\item Setze Schlüssel von $u$ auf $b$
	\item Tausche hoch, bis H-Eigensch. erfüllt
\end{enumerate}

\subsection*{ExtractMin}
\begin{enumerate}
	\item Minimum steht in Wurzel
	\item Füge letztes Blatt als neue Wurzel ein
	\item Heapify(Wurzel)
\end{enumerate}

\subsection*{InsertElement}
\begin{enumerate}
	\item Füge Element als letztes Blatt ein.
	\item Analog zu DecreaseKey
\end{enumerate}

\subsection*{Initialisierung}
Heap kann in $\bigO(n)$ aufgebaut werden.
